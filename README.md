# Mi viaje aprendiendo SQL desde cero con PostgreSQL

Este repositorio es el registro de mi aprendizaje en el mundo de las bases de datos relacionales. Decidí tomar el curso *SQL de cero* con PostgreSQL porque quería pasar de no saber nada sobre bases de datos a sentirme seguro diseñándolas, consultándolas y programando dentro de ellas.

Hoy, al mirar hacia atrás, puedo decir que logré ese objetivo. Este repo contiene todo lo que fui construyendo, practicando y entendiendo a lo largo del camino.

## 🧠 Lo que aprendí

Empecé desde lo más básico: entender qué es una base de datos relacional y cómo levantar un entorno para trabajar. Desde ahí, fui profundizando paso a paso:

- **Poner las manos en marcha**: aprendí a montar PostgreSQL con Docker y también usé Neon para tener una base en la nube sin complicaciones.
- **Los fundamentos de SQL**: dominar DDL, DML, TCL y DQL me dio la base para construir y manipular estructuras con confianza.
- **Consultas que realmente resuelven problemas**: me enfrenté a JOINs, subconsultas, CTEs recursivas y aprendí a trabajar con arreglos y datos JSON cuando las necesidades lo requerían.
- **Diseño desde cero**: pasé por todo el proceso de crear diagramas entidad-relación, identificar llaves (primarias, foráneas, candidatas, compuestas) y convertir ese diseño en una base de datos funcional.
- **Hacer que la base de datos trabaje para mí**: creé funciones personalizadas, procedimientos almacenados y triggers para automatizar lógica que antes pensaba que solo podía hacer en el código de la aplicación.
- **Ajustes finos**: aprendí a usar índices, extensiones como uuid y crypt, constraints, y a manejar eliminaciones en cascada con criterio.
- **Trabajar con el tiempo**: algo que me costaba al inicio fue manejar fechas con horas, minutos y segundos; ahora es algo que hago con naturalidad.

## 🛠️ Lo que fui construyendo

A medida que avanzaba, fui guardando acá los ejercicios, los scripts que escribía, los pequeños proyectos que armaba y las notas que me ayudaban a afianzar conceptos. Cada carpeta y cada archivo refleja un momento de ese proceso.

Si hoy entro a este repositorio, veo no solo código, sino también la evolución de cómo fui pensando las bases de datos. Desde las primeras consultas torpes hasta los procedimientos almacenados que escribo ahora con claridad.

## 📌 Para mí, esto fue...

Un curso que me llevó de cero a sentirme cómodo trabajando con PostgreSQL. Y aunque el motor que usé fue PostgreSQL, gran parte de lo que aprendí lo puedo aplicar a cualquier base de datos relacional que use SQL.

Este repo es mi prueba de ello.
